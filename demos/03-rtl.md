# מצגת מימין לשמאל

כל הפריסה מתהפכת, והקוד נשאר משמאל לימין.

---

## מה מתהפך

- הכיוון של הטקסט ושל התבליטים
- הקו הדו-גוני מתחת לכותרת, והפס בשקופית הפתיחה
- מקש החץ שמקדם את המצגת
- מחסנית הגופנים, לגופן עברי תחילה

---

## ומה לא

קוד, פלט וטבלאות של מספרים נשארים משמאל לימין — פייתון לא נקרא מימין לשמאל.

```python
def tokenize(text):
    return text.lower().split()
```

```
['a', 'short', 'sentence']
```

---

## עברית ואנגלית באותה שורה

הפונקציה `tokenize()` מקבלת מחרוזת ומחזירה **רשימה**. שם הפונקציה נשאר בכיוונו,
והמשפט סביבו בכיוונו.

| שדה | מה זה | דוגמה |
| --- | --- | --- |
| `title` | כותרת השקופית | מצגת מימין לשמאל |
| `lang` | שפה | `he` |
| `theme` | ערכת נושא | `warm` |
